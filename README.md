# Backup180

Лёгкая десктопная утилита для резервного копирования файлов и папок с масками, расписанием и запуском из системного трея.

Написана на **Tauri v2** (Rust-бэкенд) + **React / TypeScript** (интерфейс). Благодаря Tauri использует системный WebView вместо встроенного браузера, поэтому дистрибутив весит всего несколько мегабайт.

## Возможности

- **Задачи резервного копирования** — выбор одной или нескольких папок/файлов-источников и папки назначения.
- **Маски** включения (`*.docx`, `sub/*.pdf`) и исключения (`*tmp*`, `node_modules`) — сравнение по имени файла и относительному пути.
- **Группы (подпапки)** — группировка задач одного уровня в сворачиваемые папки в списке.
- **Расписание** — запуск по интервалу, ежечасно, ежедневно, еженедельно или по cron-выражению.
- **Ручной запуск** — кнопка «Запустить сейчас» для любой задачи.
- **Системный трей** — сворачивание в трей, запуск всех включённых задач из меню, закрытие окна в фон.
- **Автозапуск** при входе в систему.
- **Журнал** — история создания/изменения/удаления задач и результатов выполнения (до 1000 записей).
- **Темы** — светлая и тёмная с запоминанием выбора.
- **Адаптивный интерфейс** — изменяемая ширина и сворачивание боковой панели.

## Разработка

Установить зависимости:

```bash
npm install
```

Запустить в режиме разработки (горячая перезагрузка):

```bash
npm run tauri dev
```

## Сборка дистрибутива

```bash
npm run tauri build
```

Готовые артефакты будут в `src-tauri/target/release/bundle/`:

- `nsis/Backup180_<version>_x64-setup.exe` — установщик NSIS
- `msi/Backup180_<version>_x64_en-US.msi` — установщик MSI

Портативный исполняемый файл: `src-tauri/target/release/backup180.exe`.

Собрать только один тип установщика:

```bash
npm run tauri build -- --bundles nsis
```

## Где хранятся данные

Все задачи, журнал и настройки — в одном JSON-файле в папке данных приложения:

```
%APPDATA%\com.darts180.backup\backup-jobs.json   (Windows)
```

> Портативный `.exe` использует тот же путь. Для переноса настроек скопируйте `backup-jobs.json` в `%APPDATA%\com.darts180.backup\` на новом компьютере.

## Поведение при повторном запуске

Копирование **перезаписывает** существующие файлы в папке назначения (полное копирование при каждом запуске). Файлы, удалённые из источника, в назначении **не удаляются**.
